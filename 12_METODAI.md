# Metodai

#js #metodai

Metodas yra funkcija, susieta su objektu arba duomenų tipu.

Dažnai iškviečiamas su tašku `.`.

Pavyzdys:

```js
let text = "labas";

console.log(text.toUpperCase());
```

Rezultatas:

```text
LABAS
```

Čia `toUpperCase()` yra String metodas.

Kitas pavyzdys:

```js
let fruits = ["obuolys", "bananas"];

fruits.push("kriaušė");
```

`push()` prideda elementą į masyvą.

## Atmink
Funkcija:

```js
sayHello();
```

Metodas:

```js
text.toUpperCase();
```
