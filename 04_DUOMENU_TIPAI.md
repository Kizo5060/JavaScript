# Duomenų tipai

#js #tipai

## Number
Skaičiai:

```js
let age = 20;
let price = 10.99;
```

## String
Tekstas:

```js
let name = "Jonas";
let city = 'Kaunas';
```

## Boolean
Tik dvi reikšmės:

```js
let isOnline = true;
let isAdmin = false;
```

## `null`
Reikšmė sąmoningai yra „tuščia“ / nežinoma.

```js
let selectedUser = null;
```

## `undefined`
Kintamasis yra, bet reikšmė dar nepriskirta.

```js
let result;
```

## `NaN`
Reiškia „Not a Number“.

## `typeof`
Patikrinti tipą:

```js
let age = 20;

console.log(typeof age);
```

Rezultatas:

```text
number
```

## String su backticks

```js
let name = "Jonas";

console.log(`Labas, ${name}`);
```
