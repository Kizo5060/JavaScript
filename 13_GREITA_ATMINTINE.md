# Greita atmintinė

#js #cheatsheet

## Kintamieji

```js
let age = 20;
const name = "Jonas";
```

## Išvedimas

```js
console.log("Labas");
```

## IF

```js
if (age >= 18) {
    console.log("Suaugęs");
} else {
    console.log("Nepilnametis");
}
```

## Funkcija

```js
function sum(a, b) {
    return a + b;
}
```

## Arrow function

```js
const sum = (a, b) => a + b;
```

## FOR

```js
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

## WHILE

```js
let i = 0;

while (i < 5) {
    console.log(i);
    i++;
}
```

## Array

```js
let items = ["a", "b", "c"];
console.log(items[0]);
```

## Object

```js
let user = {
    name: "Jonas",
    age: 20
};

console.log(user.name);
```

## Patikrinimai

```js
===   // lygu
!==   // nelygu
>     // daugiau
<     // mažiau
>=    // daugiau arba lygu
<=    // mažiau arba lygu
&&    // IR
||    // ARBA
!     // NE
```
